# 🧰 Isra's Bioinformatics Toolbox

Hello theree!

This repository is my personal collection of bioinformatics scripts, utilities, and small automation pipelines that I've built while learning bioinformatics and working on different research projects.

Over time, I found myself writing the same commands and scripts repeatedly. This toolbox is my way of organizing those reusable pieces into one place so they can be used across different workflows instead of being rewritten every time.

Here you'll find Bash, Python, and R scripts for common bioinformatics tasks, ranging from simple file handling and automation to complete analysis pipelines. 
Every script in this repository is something I've learned, used, tested, or improved during my journey.

## What's in the repo?

- Bash scripts for Linux automation
- Python utilities for data processing
- R scripts for analysis and visualization
- Reusable bioinformatics pipelines

This toolbox is a work in progress and will continue to grow as I learn new tools(in this lifetime), workflows, and best practices in bioinformatics.

If you find something useful, feel free to use it, modify it, or contribute.

Happy coding, guys! :)
